### Назначение

**Сkill: Web Research**

## Описание

Использует сервер Browser Vision MCP (порт 8909) для автономного исследования веба. Позволяет навигировать, извлекать текст, ссылки, снимки экрана, обнаруживать CAPTCHAs и копировать сети запросы, а также возвращать структурированную информацию. По умолчанию читаемый; активные действия требуют явного одобрения.

## Ввод

- `query` или `urls` — поисковая строка или список URL для исследования
- `extract_links` — выделение ссылок (по умолчанию: true)
- `screenshot` — снимки экрана (по умолчанию: false)
- `max_pages` — максимальное количество страниц, которые нужно посетить (по умолчанию: 5)
- `depth` — глубина следования ссылок (по умолчанию: 0, нет следования)
