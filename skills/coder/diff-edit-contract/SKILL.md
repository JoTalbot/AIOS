# Diff-контракт автокодера AIOS

Существующие файлы меняются ТОЛЬКО через SEARCH/REPLACE-блоки:

```
<<<<<<< SEARCH
<точные строки из файла>
=======
<новые строки>
>>>>>>> REPLACE
```

## Причина 90% провалов

SEARCH-блок не совпал ДОСЛОВНО: перепечатал по памяти, потерял отступ,
пропустил/добавил пустую строку, «улучшил» форматирование в SEARCH-части.

## Правила успешного блока

1. Копируй SEARCH-фрагмент ПОСИМВОЛЬНО из присланного текста файла (даже опечатки).
2. Минимальный размер: 1–10 строк. Один блок = одно место правки.
3. Для однозначности добавляй 1–2 строки контекста сверху/снизу.
4. Отступы и пустые строки — как в файле, trailing spaces не добавлять.
5. Если нужно править функцию целиком — SEARCH = вся функция от `def` до конца тела.
6. Нельзя: удалять функции/классы без необходимости, eval/exec, «оптимизировать»
   непрошенные куски — self_protection отклонит как деградацию.
7. Если файл прислан «окнами» (OUTLINE + фрагменты) — правь только показанные
   фрагменты; текст вне фрагментов недоступен, не выдумывай его.

## Сопоставление движка (для понимания)

exact → rstrip (игнор хвостовых пробелов) → blank-insensitive. Рассчитывай на
exact — остальное подстраховка, а не норма.
