# New Architecture

The `new` branch is the isolated integration line for AIOS new architecture.

Scope: vNext orchestration/execution, agent-tool permission boundaries, memory/persistence, recovery/checkpoints, leases and audit contracts, plus the agent operating system needed for multi-machine parallel development.

General reusable agent instructions and skills are migrated from `JoTalbot/refund`; product-specific refund/returns skills are excluded.
