# V4-прототип: эмиттер MM-сигналов (модель → Telegram) + скоринг

**Дата:** 2026-08-15 | Скрипты: `mm_signal_emitter.py`, `mm_signal_score.py`
**Сервис:** `aios-mm-signal-emitter.timer` (каждые 5 мин, ETH/BNB/SOL)

## Как работает
1. Каждые 5 минут: обучение CatBoost h1-направления на всех доступных ws-данных символа
   (таргет — движение mid за 60с, только движения);
2. Предсказание текущего направления по последним снапшотам;
3. При уверенности (prob_up ≥ 0.60 → UP, ≤ 0.40 → DOWN) — отправка в TG владельца + лог;
4. `mm_signal_score.py` сверяет каждую эмиссию с фактическим движением через 60/180с —
   накапливает live-точность.

## Первые эмиссии (2 прогона)
- BNB: DOWN (prob 0.003, 0.044) — промах (1 движение, 0 точных);
- SOL: UP (prob 0.958) — попадание (100%);
- ETH: FLAT (0.46-0.58) — без сигнала.
- **Итого: 50% (1/2) на движениях — выборка ничтожна, статистика накопится за дни.**

## Значение
Это первый рабочий контур «сигнал → человек» из quant-направления. Если live-точность
на движениях устоится ≥65-70% за 2-4 недели (на горизонте 1-3 мин, который подтверждён
для ETH/BNB в V2), контур можно превратить в сигнальный продукт (подписка/канал).
Сейчас — owner-only, без обещаний точности.

## Статус
- Эмиттер: активен (каждые 5 мин); лог: data/reports/mm_signal_emitted.jsonl;
- Скоринг: `python scripts/mm_signal_score.py`; точность добавлена в weekly-digest;
- BTC исключён (mid на 1с статичен — нет обучающих движений).
