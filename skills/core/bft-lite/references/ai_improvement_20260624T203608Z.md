### Назначение

**bft-lite** — это навык для улучшения безопасности и краткости в проекте Octopus. Он обеспечивает безопасность и эффективность работы системы путем применения следующих алгоритмов:

1. **Threshold Signatures**: Для выполнения важных решений.
2. **CRDT (Conflict-Resolution Data Types)**: Для обмена данными между узлами в сети.
3. **Reputation-Weighted Voting**: Для принятия решений с учетом репутации участников.

### 3 bounded улучшения без деструктивных действий

1. **Интеграция с Chaos Test Guard**: Улучшение критической функции системы путем автоматического тестирования и отлова ошибок.
2. **Создание буферного режима (bounded context)**: Разделение системы на более низкую и высокую уровни, что уменьшает риск деструктивных изменений.
3. **Интеграция с Telegram**: Улучшение общения и отслеживания состояния системы через каналы Telegram.
