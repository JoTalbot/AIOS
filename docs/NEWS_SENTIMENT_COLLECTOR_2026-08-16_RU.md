# N1: новостной коллектор + LLM-сентимент — запущен

**Дата:** 2026-08-16 | Скрипт: `scripts/collect_news_sentiment.py`
**Сервис:** `aios-news-sentiment.timer` (ежечасно в :20)

## Что делает
- Собирает крипто-новости из RSS (CoinTelegraph, CoinDesk, CryptoSlate);
- Сентимент-анализ заголовков через **Gemini 2.5 Flash** (ключи GEMINI_API_KEY_1..3 из .env);
- Пишет в `data/quant/news_sentiment.jsonl`: ts, source, title, url, sentiment (-1..1), label, coins;
- Fallback-провайдеры: OpenRouter (402 - нет баланса), GROQ (403 - региональная блокировка) — Gemini основной.

## Отладка (важные уроки)
- GROQ: все 8 ключей 403 Forbidden (региональная блокировка);
- OpenRouter: 402 Payment Required (нет баланса на аккаунте);
- Gemini: ключи в URL (query param), БЕЗ Authorization-Bearer (иначе 401);
- модель gemini-2.0-flash не существует — актуальна gemini-2.5-flash;
- дубль-определение score_batch перекрывало новую версию (Python берёт последнее) — удалено.

## Первый сбор (65 новостей)

  "-0.9 недельный пробой $62.5k может запустить волну продаж BTC" — оценки адекватны.
