# AIOS: сценарии приложений Android

Обновление добавляет безопасные сценарии для реального телефона, подключённого через WireGuard и AIOS Companion.

## Приложения

| Приложение | Пакет | Режим |
|---|---|---|
| WhatsApp | `com.whatsapp` | Поиск чата, черновик, отдельное подтверждение отправки |
| iMe Messenger | `com.iMe.android` | Черновик в вручную открытом чате, отдельное подтверждение отправки |
| Uklon Passenger | `ua.com.uklontaxi` | Статус, уведомления, черновик маршрута; без заказа поездки |
| Uklon Driver | `ua.com.uklon.uklondriver` | Статус и подтверждаемое открытие |
| EasyWay | `com.eway` | Статус, уведомления, черновик маршрута; без фоновой геолокации |
| A-Bank | `ua.com.abank` | Только уведомления, статус и подтверждаемое открытие |
| Privat24 | `ua.privatbank.ap24` | Только уведомления, статус и подтверждаемое открытие |

## Telegram-команды

### WhatsApp на телефоне

- `WhatsApp статус`
- `открой чат WhatsApp: Имя`
- `WhatsApp черновик: текст ответа`
- `прочитай WhatsApp` — читает только видимую часть уже открытого чата по явной команде.

Процесс отправки всегда состоит из двух шагов:

1. Подтвердить вставку черновика в текущий чат.
2. После проверки текста на экране отдельно подтвердить нажатие **«Отправить»**.

Перед нажатием «Отправить» AIOS ещё раз сверяет текст в поле ввода с подтверждённым черновиком. Если пользователь сменил чат или текст, отправка блокируется.

### iMe

- `iMe статус`
- `открой чат iMe: Имя`
- `iMe черновик: текст`

Открытие чата, вставка черновика и отправка — отдельные подтверждаемые шаги. Как и в WhatsApp, поиск открывает только точное совпадение имени; текст чата не попадает в технические логи.

### Uklon

- `Uklon статус`
- `открой Uklon`
- `открой Uklon Driver`
- `маршрут Uklon: откуда -> куда`
- `продолжи маршрут Uklon` — после ручного выбора первой точки предлагает ввести вторую.
- `калибруй Uklon` — безопасно проверяет наличие элементов адресов, без ввода адреса и без заказа.

Последняя команда открывает Passenger, проверяет элементы выбора адресов и сохраняет короткоживущий приватный черновик маршрута. После отдельного второго подтверждения AIOS может ввести поисковый запрос для одной точки, но **не выбирает подсказку**, не создаёт заказ, не принимает поездку и не инициирует списание денег. Точный адрес всегда выбирается вручную на телефоне.

### EasyWay

- `EasyWay статус`
- `открой EasyWay`
- `маршрут EasyWay: остановка или адрес`
- `калибруй EasyWay` — проверяет наличие безопасного элемента поиска маршрута без ввода адреса.

EasyWay зарегистрирован как `com.eway`. После второго подтверждения AIOS может ввести запрос в поле поиска, но не выбирает остановку или маршрут вместо владельца. Маршрут хранится только в краткоживущем файле с правами `0600`; GPS не включается и не читается в фоне.

### Банки

- `A-Bank статус`, `открой A-Bank`
- `Privat24 статус`, `открой Privat24`

Нет сценариев для балансов, карт, OTP/PIN, биометрии, переводов, платежей или подтверждений банковских операций.

## Потенциальные лиды из мессенджеров

AIOS создаёт локальную очередь для новых уведомлений WhatsApp и iMe:

- `лиды телефона`
- `лиды WhatsApp`
- `лиды iMe`
- `отметь лид 1 обработанным`

Карточка содержит только источник и время события. Имя, текст уведомления, номер телефона и содержимое чата в очередь не копируются. Отметка «обработан» меняет только локальный статус.

Команда `создай CRM задачу для лида 1` после отдельного подтверждения создаёт только локальную follow-up задачу: «открыть чат и проверить обращение». Команды `CRM задачи телефона` и `закрой CRM задачу 1` показывают и завершают эти задачи с отдельным подтверждением.

Для явно выбранной задачи можно подготовить черновик, не отправляя его автоматически:

```text
подготовь черновик по CRM задаче 1 в WhatsApp: Имя | Текст ответа
```

Открытие чата, вставка черновика и отправка остаются отдельными подтверждаемыми этапами.

Задачи получают только технический возраст: новая, внимание после часа и просроченная после суток. Это не меняет CRM-клиента, сообщение или ответ автоматически.

Каждые пять минут AIOS проверяет появление новых карточек и может прислать владельцу одну краткую сводку с количеством по источникам и числом открытых/просроченных follow-up задач. Старые карточки при первом запуске берутся как база и не вызывают массовую рассылку.

## Центр управления телефоном

Команда `центр телефона` или `статус автоматизации телефона` показывает одну обезличенную сводку: ADB, Companion, доступность приложений, калибровки интерфейсов, лиды, CRM follow-up, таймеры и безопасный аудит.

Команда `восстановление телефона` запускает безопасную диагностику ADB/WireGuard/Companion и сообщает только требуемое действие, без экрана, координат или содержимого приложений.

Команда `статус камеры и микрофона телефона` показывает только готовность разрешений и факт отключённого фонового захвата. Она не делает фото и не начинает запись звука.

В AIOS Companion появилась кнопка ручного запроса разрешения микрофона для будущих явных действий. Нажатие кнопки не начинает запись; микрофон остаётся выключенным, пока не будет отдельной конкретной команды.

В 20:00 по Киеву AIOS может присылать владельцу ежедневную техническую сводку этих показателей. При первоначальном включении текущий день берётся как база, без немедленной рассылки.

По воскресеньям в 20:10 по Киеву доступен недельный обезличенный отчёт по лидам и CRM follow-up. Его также можно вызвать командой `недельный отчёт телефона`.

## Безопасный журнал действий телефона

Команда `журнал телефона` показывает технические события: открытие приложения, калибровку интерфейса, создание черновика, отмену или подтверждённое нажатие отправки, а также этапы маршрута.

Журнал не содержит текст сообщений, имена, номера, маршруты, GPS-координаты, фото, аудио, файлы или координаты нажатий.

## Защита данных

- Companion по умолчанию возвращает **обезличенную** структуру UI: координаты, роли и package активного окна, без текста экрана.
- Полный текст UI запрашивается только внутри подтверждённого сценария и не записывается в логи.
- Для активного действия AIOS проверяет package активного приложения. Если Companion не может подтвердить foreground package, вставка и нажатия блокируются.
- Тексты черновиков и маршрутов имеют короткий TTL и сохраняются с правами `0600`.
- OTP/PIN-подобные последовательности, номера карт и телефоны маскируются в выдаче сообщений и уведомлений.
- HTTP gateway Companion привязывается только к адресу WireGuard `10.203.x.x`, а не к Wi‑Fi/мобильной сети.

## Ограничения

- Сообщения не отправляются автоматически.
- Открытие WhatsApp-чата может пометить его как прочитанный — перед этим показывается предупреждение.
- Доставка сообщения не заявляется как факт: после подтверждения AIOS сообщает только о нажатии кнопки отправки.
- Если пользователь вручную меняет активное приложение или текст на телефоне, сценарий останавливается безопасно.
