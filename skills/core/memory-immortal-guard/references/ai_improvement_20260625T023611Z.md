### 1) Контекст

**Назначение:**
Создание и реализация Memory Immortal Guard (MIG), который обеспечивает бесконечную память для Octopus проекта с использованием технологий pack replication, eternal snapshot и off-host copies. Этот навык используется в качестве дополнительного уровня защиты и резервной копии для важных данных.

### 2) Бounded улучшения

1. **Бесконечная память (pack replication)**:
   - Увеличение количества байтов, которые могут быть сохранены в памяти.
   - Повышение скорости и производительности при обработке больших объемов данных.

2. **Eternal snapshot**:
   - Создание бесконечных снимков для обеспечения непрерывного доступа к данным.
   - Улучшение надежности и резервной копии, особенно в случае отказа основного хранения.

3. **Off-host copies**:
   - Сохранение данных на внешних устройствах (например, дисках) для обеспечения непрерывного доступа
