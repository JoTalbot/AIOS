### Назначение

**Концепция:**
Octopus memory invariant audit (Октоусс Память Согласованность аудит) — это проверка на наличие хотя бы одного индивидуального экземпляра в памяти, который не находится на одной машине с местом сохранения данных. Цель этого навыка заключается в обеспечении безопасности и надежности при хранении данных на основе принципа "все данные должны быть копированы на отдельную машину".
