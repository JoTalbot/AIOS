# Hetzner host overrides

Exact base-unit variants, сохранённые для объяснения текущего runtime. Эти файлы не копируются поверх canonical units автоматически.

- `aios-colab-keeper.service` — inactive/disabled runtime variant.
- `aios-olx-collector.service` — active host-specific query set and limits.

См. `deploy/systemd/README.md` и runtime drift audit.
