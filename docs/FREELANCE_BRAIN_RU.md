## 🎯 1. Идея и Концепция

**«МОЗГИ» AIOS** — это подсистема интеллектуальной самообеспеченности (**Self-Funding Subsystem**). 
Система обладает собственным кошельком, сканером рынка фриланс-задач, модулем оценки квалификации (LLM Qualification Engine) и автокодером для решения IT-задач.

### Главный финансовый показатель:
$$\text{Self-Sufficiency Index (SSI)} = \frac{\text{Совокупная выручка от задач (\$)}}{\text{Операционные расходы на VPS и LLM API (\$/мес)}}$$

При **SSI >= 100%** система полностью покрывает свои серверные затраты и оплату платных LLM-моделей, не требуя вложений владельца.

## 🔐 3. Модуль Криптокошелька (`aios_core/crypto_wallet.py`)

Модуль `AIOSWalletManager` управляет адресами и резервами средств:

* **Файл хранилища:** `/root/AIOS/data/.wallet_vault.json` (права `0600`).
* **Файл реестра:** `/root/AIOS/data/self_funding_ledger.json`.
* **Поддерживаемые сети:** EVM (Ethereum, Polygon, Arbitrum, Base, BSC), TRC20 (USDT Tron), Solana.
* **Авто-распределение бюджета:**
  * `50%` — Резерв на покупку токенов и оплату платных LLM API (OpenAI, Anthropic, Groq).
  * `50%` — Резерв на продление VPS-сервера ($15/мес) и инфраструктурных расходов.

---

## 🤖 4. Фриланс-мозг (`aios_core/freelance_brain.py`)

* **Сканирование:** Ищет задачи по категориям `python_scripting`, `web_scraping`, `bot_dev`, `data_analysis`, `bug_fixing`.
* **Оценка Feasibility Score:** Анализирует сложность через `LLMBalancer`. Если score >= 0.7 — формируется заявка.
* **Авто-решение задач:** Автокодер генерирует чистый Python-код с обработкой ошибок и компиляцией.

## 🛠️ 5. Управление сервисом

### Команды в консоли:
```bash
# Разовый прогон сканера и решения задач
python3 /root/AIOS/run_freelance_brain.py

# Проверка статуса фонового сервиса
systemctl status aios-freelance-brain.service

# Просмотр логов работы
journalctl -u aios-freelance-brain.service -f
```

### Взаимодействие через Telegram-бота:
Владельцу отправляются уведомления при обнаружении подходящих фриланс-задач и зачислении средств:
* `«подтверди бид N»` — подтвердить отправку отклика клиенту.
* `«подтверди вывод N»` — санкционировать выплату или покупку ключей LLM.
