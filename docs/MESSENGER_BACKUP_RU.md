# Локальные бэкапы профилей мессенджеров

`run_messenger_profile_backup.py` создаёт локальный архив авторизованных
профилей Signal и Viber в:

```text
backups/messenger_profiles/<UTC-время>/profiles.tar.gz
```

Архивы и манифесты имеют права `0600`, каталоги — `0700`. Кэши браузеров и
GPU не включаются. По умолчанию хранится 14 последних снимков.

Автоматический ежедневный запуск обеспечивает:

```text
aios-messenger-profile-backup.timer
```

WhatsApp Web/Chrome-профиль намеренно не включён: он большой и подключение
WhatsApp отложено пользователем. Его можно добавить отдельной осознанной
политикой после авторизации WhatsApp.
