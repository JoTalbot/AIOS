# AIOS Companion для Android

`android_companion/` — минимальное нативное Android-приложение-компаньон для
реального телефона. Оно не заменяет ADB, а добавляет те возможности, для
которых ADB недостаточно или ненадёжен на Android 15.

## Принцип безопасности

- gateway работает на телефоне на порту `8765`;
- сервер обращается к нему только через внутренний WireGuard-IP;
- каждый запрос обязан содержать закрытый `X-AIOS-Token`;
- нет публичного HTTP-порта и нет облачной отправки уведомлений;
- уведомления, геолокация и файлы выдаются только после Android-разрешений;
- чтение интерфейса активного приложения требует отдельного включения сервиса
  "AIOS Companion управление приложениями" в настройках доступности Android;
- никаких SMS, звонков, платежей, банковских действий или камеры в фоне без
  отдельного явного расширения и подтверждения владельца;
- после перезагрузки телефона Companion пытается восстановить gateway, если
  сохранён AIOS-токен и Android разрешает запуск foreground-сервиса.

## Реализованные read-only endpoints

```text
/health
/battery
/apps
/permissions
/location
/notifications
```

## Сборка

```bash
export ANDROID_HOME=/opt/android-sdk
/opt/aios/gradle/gradle-8.10.2/bin/gradle :app:assembleDebug
```

Для первой версии используется debug-подпись и установка через уже
авторизованный ADB-канал. Перед распространением приложения за пределы
личного телефона следует перейти на отдельную release-подпись.
