# T2 momentum — paper-контур запущен

**Дата:** 2026-08-16 | Скрипт: `scripts/run_t2_momentum.py` (+`tests/test_t2_paper.py`, 28 тестов)

## Правило (из бэктеста, docs/MOMENTUM_STRATEGIES_RESULT)
LONG BTC, пока close > SMA50 (1d); иначе кэш. Сигнал по последнему ЗАКРЫТОМУ бару.
Издержки 0.15% при каждом переходе (вход/выход).

## Реализация
- Ежедневно 01:30 UTC (после закрытия дня): fetch closes (Yahoo, фолбэк Binance spot),
  сигнал, mark equity, запись в лог, TG-уведомление при смене позиции;
- state: `data/t2_paper_state.json` (позиция, equity, трейды);
- история: `data/t2_paper_equity.jsonl` (день, close, sma50, сигнал, equity, bh_equity);
- идемпотентность: повторный запуск того же дня не дублирует;
- `/quant` показывает позицию/equity/BH.
