### Назначение

**Концепция:**

Создание ежедневного манифеста для каждого backend Octopus, который содержит SHA-хэши sha1 и sha256 файлов. Этот манифест используется для проверки целостности данных на каждом backend.

### 3bounded улучшения без деструктивных действий

1. **Сохранение манифеста в отдельном каталоге:**
   - Манифесты будут храниться в `/var/lib/octopus/manifests/`, что обеспечит безопасность и простоту аудита.
   
2. **Расширение функциональности для AWS S3 и EC2 Node:**
   - Добавление поддержки для backend `aws_s3` и `aws_ec2_node`.
   - Восстановление функции, которая собирает SHA-хэши файлов с этих backend.

3. **Добавление тестирования на основе отчетов:**
   - Создание тестов, которые проверяют правильность сборки манифестов и их совместимость между backend'ами.
