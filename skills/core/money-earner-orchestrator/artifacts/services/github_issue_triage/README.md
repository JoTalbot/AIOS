# github_issue_triage

Цена: $15
Максимальное время выполнения: 600 секунд
Лимит CPU: 100%
Лимит памяти: 512 МБ
Результат: ranked issue report

## Входные данные

- описание задачи;
- целевая система или репозиторий;
- критерии приёмки;
- idempotency key;
- подтверждение оплаты или бюджета.

## Безопасность

Внешние изменения выполняются только через глобальный lock. Автоматическое принятие заказов отключено.
