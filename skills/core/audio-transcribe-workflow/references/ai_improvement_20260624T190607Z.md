### Назначение

**Контекст проекта Octopus:**
1. **Валидация и обработка входных данных:** Проверка на наличие ошибок в загружаемых аудиофайлах, предварительное сегментирование по VAD (Voice Activity Detection) для определения активного звука.
2. **Использование Whisper API:** Выполняется распознавание голоса с использованием модели Whisper на основе чанков аудиофайла, в которых каждый чанк имеет длину 180 секунд.
3. **Экспериментальная система ECAPA для диаризации:** Используется модель ECAPA для определения личности каждого участника разговора.
4. **Удаление шума и корректировка качества:** Включается процесс удаления шума с помощью модели Corrupt, что обеспечивает более качественный результат распознавания голосов.
5. **Обновление графика людей (people_graph) и векторов (vectors):** После обработки аудиофайла происходит обновление графика участников разговор
