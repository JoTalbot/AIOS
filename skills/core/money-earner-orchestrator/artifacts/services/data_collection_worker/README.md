# data_collection_worker

Цена: $35
Максимальное время выполнения: 1800 секунд
Лимит CPU: 150%
Лимит памяти: 768 МБ
Результат: json/csv artifact

## Входные данные

- описание задачи;
- целевая система или репозиторий;
- критерии приёмки;
- idempotency key;
- подтверждение оплаты или бюджета.

## Безопасность

Внешние изменения выполняются только через глобальный lock. Автоматическое принятие заказов отключено.
