# 📖 Руководство по созданию шаблонов AI Advisor

## 🎯 Что такое шаблоны?

Шаблоны — это готовые ответы для типовых ситуаций (вопрос о цене, доставке, наличии). Они используют **Jinja2** — мощный язык шаблонов с переменными, условиями и циклами.

---

## 📝 Базовый синтаксис

### Переменные
```jinja
Здравствуйте, {{ customer.name }}!
Цена: {{ product.price }} грн.
```

### Условия (если/иначе)
```jinja
{% if product.in_stock %}
Товар в наличии! ✅
{% else %}
Товар закончился. Ожидаем поступление {{ product.expected_date }}.
{% endif %}
```

### Циклы (для списков)
```jinja
Доступные способы доставки:
{% for option in delivery_options %}
  • {{ option.name }} — {{ option.price }} грн ({{ option.days }} дн.)
{% endfor %}
```

---

## 🔧 Доступные переменные

### Контекст клиента
| Переменная | Тип | Описание |
|---|---|---|
| `customer.name` | string | Имя покупателя |
| `customer.language` | string | Язык ('uk', 'ru', 'en') |
| `customer.is_vip` | boolean | VIP-статус |

### Контекст товара
| Переменная | Тип | Описание |
|---|---|---|
| `product.title` | string | Название товара |
| `product.price` | number | Базовая цена |
| `product.suggested_price` | number | Динамическая цена (с учётом истории торгов) |
| `product.in_stock` | boolean | Наличие на складе |
| `product.delivery_options` | list | Список способов доставки |

### Контекст продавца
| Переменная | Тип | Описание |
|---|---|---|
| `seller.name` | string | Название магазина |
| `seller.phone` | string | Телефон для связи |

## 💡 Примеры готовых шаблонов

### 1. Приветствие VIP-клиента
```jinja
{% if customer.is_vip %}
Здравствуйте, {{ customer.name }}! 👋
Рады видеть вас снова! Для вас действует скидка 5%.
{% else %}
Здравствуйте, {{ customer.name }}!
{% endif %}
```

### 2. Ответ на вопрос о цене (с динамической ценой)
```jinja
Добрый день, {{ customer.name }}!

Товар "{{ product.title }}" доступен по цене:
💰 {{ product.suggested_price }} грн

({{ pricing_reason }})

Доставка: Новая Почта, Укрпочта.
```

### 3. Ответ при отсутствии товара
```jinja
Здравствуйте, {{ customer.name }}!

К сожалению, "{{ product.title }}" временно отсутствует.
Ожидаем поступление: {{ product.expected_date }}

Можем предложить аналог: {{ product.alternative_title }}
```

## 🛠️ Как создать шаблон через UI

1. Откройте дашборд: `http://localhost:8080/advisor/templates`
2. Нажмите **"➕ Добавить шаблон"**
3. Заполните поля:
   - **Название**: "Ответ на вопрос о цене"
   - **Намерение**: `price_inquiry`
   - **Платформа**: `olx` (или "Все")
   - **Содержимое**: Вставьте Jinja2-шаблон
   - **Переменные**: JSON-список используемых переменных
4. Нажмите **"Сохранить"**

---

## 🧪 Тестирование шаблона

В том же дашборде есть раздел **"🧪 Живой предпросмотр"**:
1. Выберите шаблон из списка
2. Введите тестовый JSON-контекст:
```json
   {
     "customer": {"name": "Иван", "is_vip": true},
     "product": {"title": "iPhone 15", "price": 30000, "suggested_price": 28500},
     "pricing_reason": "Лояльность: скидка 5%"
   }
```
3. Нажмите **"▶ Запустить предпросмотр"**
4. Увидите отрендеренный текст

## ⚠️ Важные правила

1. **Draft-only mode**: AI Advisor только предлагает черновики. Менеджер должен проверить и одобрить перед отправкой.
2. **Соответствие Конституции**: Шаблоны не должны содержать вводящей информации о состоянии товара.
3. **Языковая версия**: Создавайте отдельные шаблоны для UA/RU/EN или используйте условия `{% if lang == 'uk' %}`.

## 🆘 Нужна помощь?

Если шаблон не работает:
- Проверьте синтаксис Jinja2 (нет ли незакрытых `{% if %}`)
- Убедитесь, что все обязательные переменные переданы в контексте
- Посмотрите логи: `aios_core/advisor/templates_engine.py` выводит ошибки
