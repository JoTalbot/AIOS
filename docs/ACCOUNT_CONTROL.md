# Управление Google и Instagram через диалог в Telegram

Бот AIOS (`run_telegram_bot.py`) управляет **Google** и **Instagram** обычным
«человеческим» текстом (и даже голосом) в чате — без команд и API.

## Как это работает
1. Вы пишете боту фразу («проверь мою почту») или отправляете голосовое.
2. Бот распознаёт намерение и запускает хелпер `run_account_control.py`
   (под `xvfb-run` для браузерных операций).
3. Хелпер работает через **Chrome Twin** (ваш профиль Chrome: Google
   `jo.talbot@gmail.com`, Instagram `@jo.talbot`), почта — через **IMAP/SMTP**.
4. Бот отвечает текстом и/или присылает **скриншоты и файлы**.

## Голосовое управление 🎙
Отправьте боту **голосовое сообщение** — бот распознает речь (Gemini API)
и выполнит команду: «проверь почту», «покажи инсту», «отправь письмо …».
Проверено: «Проверь мою почту.» → выполняется.



## Массовая выгрузка склада на OLX
- **«выложи весь склад» / «выгрузи склад на олх»** — бот читает data/inventory.json,
  генерирует объявления (цена из склада) и показывает список → после «да» публикует
  каждое с паузой 25с (защита от модерации).
- CLI: `python run_olx_ad_gen.py export_sklad [--confirm] [--limit N] [--pause SEC]`
- При публикации создаётся запись в data/olx_published.json (журнал «мои объявления»).
- Заголовок автоматически дополняется до 16+ символов (требование OLX).


## SMS-уведомления (автоматически)
- Каждые 2 минуты проверяются новые SMS телефона (Messages for Web) через
  `run_sms_alerts.py` (таймер aios-sms-alert.timer).
- Уведомление в Telegram приходит, если: есть 4-8-значный код подтверждения,
  отправитель из списка (OLX, Новая Почта, Stocar, банки, операторы и т.п.)
  или текст содержит «код/посылка/ТТН/отправлено» и т.п. Промо-рассылки не шлются.
- Управление ботом: «включи смс-уведомления» / «выключи смс-уведомления» /
  «статус смс-уведомлений».
- База: data/sms_alerts_state.json. Инициализация: run_sms_alerts.py --init.

## Полный цикл продажи
- «продал фару за 1800» → бот: списывает деталь со склада, записывает продажу
  в финансы и автоматически убирает объявление с OLX (из журнала olx_published.json).

## SMS — Google Messages for Web (телефон +380959052288)
Все SMS телефона дублируются в messages.google.com/web (профиль Chrome Twin).
Команды бота:
- **«мои смс» / «последние смс» / «проверь смс»** — последние SMS (отправитель, текст, код).
- **«найди код из смс» / «код подтверждения»** — последний код (4-8 цифр) из SMS.
  Можно уточнить отправителя: «код из смс от олх».
- **«прочитай смс от <имя/номер>» / «переписка <имя>»** — переписка с контактом.
- **«отправь смс <номер>: <текст>»** — отправить SMS с телефона (после «да»).
- **«покажи смс» / «скрин смс»** — скриншот Messages for Web.

CLI:
```bash
python run_account_control.py messages profile            # проверка привязки
python run_account_control.py messages latest --limit 10  # последние SMS
python run_account_control.py messages code [отправитель] # код подтверждения
python run_account_control.py messages read "<имя>"       # переписка
python run_account_control.py messages send "<номер>" "текст" --confirm
python run_account_control.py messages screenshot
```

Chrome для Messages держится как сервис `aios-chrome-vnc` (CDP 127.0.0.1:9222);
адаптеры подключаются к нему, а не запускают второй браузер (иначе конфликт профиля).
Телефон привязан через QR: один раз открыть VNC и отсканировать.

## Дайджесты и уведомления (автоматически)
- **Утренний дайджест** (`run_digest.py`): почта + события дня + Instagram —
  каждый день в **05:00 UTC (08:00 Киев)** через `aios-digest.timer`.
- **Алерты на важные письма** (`run_mail_alerts.py`): каждые 15 минут
  проверяет IMAP на письма с ключевыми словами (срочно, важно, invoice,
  security, github и т.п., настраивается `MAIL_ALERT_KEYWORDS` в `.env`),
  шлёт уведомление; повторы исключены state-файлом.
- Вручную: команда **«дайджест»** или `/digest` в чате.

## Безопасность
- Опасные действия (отправка письма/ответа, создание события, лайк,
  подписка, сообщение в Direct) — **только после «да»**.
- Фото/файлы из чата сохраняются локально.
- Браузерные операции — под X-дисплеем (headless блокируется).
