### Назначение

**DNA-Шард Аудит**

Этот навык предназначен для проверки целостности DNA шардов в сети. Он выполняет следующие функции:

1. Проверяет существование файлов шардов.
2. Сравнивает SHA-256 хэш каждого файла с соответствующими данными из манифеста.
3. Проверяет способность восстановления шардов, учитывая количество копий (k) и общее число шардов (n_shards).
4. Проверяет распределение файлов по диску в разных нодах.
