### Назначение

**Название:** Geo-Latency Resolver (Географический Ускоритель)

**Ключевые слова:** 
- Географическая латентность
- Расчет маршрута
- Автоматическое нахождение ближайшего сервера
- Скорость загрузки

### 3 bounded улучшения без деструктивных действий

1. **Улучшение производительности:**
   - Реализовать географический ускоритель, который бы автоматически определял ближайший сервер для запросов и использовал его в качестве источника данных.
   
2. **Улучшение безопасности:**
   - Создать механизм проверки на наличие вредоносного программного обеспечения (вирусов) на всех используемых ресурсах, чтобы предотвратить возможные атаки.

3. **Улучшение удобства использования:**
   - Разработать функцию, которая бы автоматически определяла и упрощала процесс выбора сервера для загрузки данных, исключая необходимость пользователя вводить адрес IP или DNS-адрес.
