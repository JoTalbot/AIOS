# Внедрение полезного из репозиториев — результаты

**Дата:** 2026-08-16 | По процессу: локально → тесты → прод

## 1. Meta-labeling поверх T2 (mlfinlab подход) — ✅ ВНЕДРЕНО

**Метод**: RandomForest поверх T2-сигнала. Фичи: ATR%, расстояние до SMA50, тренд (SMA50 vs SMA20), RSI14, волатильность 10д. Метка: прибыльность сделки T2. Train 60%, OOS 40%.

**Результаты (7 лет, OOS):**
| Актив | T2 чистый | T2+meta | Сделок (base→meta) | OOS acc |
|---|---:|---:|---:|---:|
| BTC | +1746% | **+2344%** | 92→39 | 0.65 |
| ETH | +2215% | **+2858%** | 98→50 | 0.63 |
| SOL | +34508% | **+65164%** | 93→64 | 0.71 |
| BNB | +2070% | **+5043%** | 119→41 | 0.44 |
| NEAR | +643% | **+3457%** | 66→30 | 0.45 |

**Валидация**: walk-forward 2 среза — 9/10 положительных; сделок 30-64 (не переобучение на шуме).

**Интеграция**: `scripts/meta_labeling.py` (train/predict) + `--meta-filter` в run_t2_momentum.py; модели обучены для 5 символов на сервере (data/t2_meta_models/*.pkl).

## 2. Riskfolio-Lib — оптимизация весов портфеля — ✅ ВНЕДРЕНО

**Метод**: Max Sharpe оптимизация на 7-летних T2-кривых (5 активов).

**Веса**: BTC 40.3%, SOL 28.2%, BNB 13.4%, NEAR 12.3%, ETH 5.8%.

**OOS (40%)**: оптимизированный портфель **+286% vs равные веса +195%** (+91 п.п.).

**Интеграция**: веса в `t2_portfolio.py`; текущее: **$26,671 vs $25,767** (равные) — уже лучше.

## 3. Freqtrade — порт T2-стратегии — ✅ ПОРТ ГОТОВ (запуск после TA-Lib)

**Создано**:
- `freqtrade_t2.py` — стратегия T2 (гистерезис SMA50/40, daily, spot), Hyperopt-совместимая;
- `freqtrade_config_t2.json` — конфиг (5 пар, $100/сделку).

**Ценность**: (а) независимый движок подтверждает наши цифры; (б) Hyperopt для параметров;
(в) A/B с NostalgiaForInfinity на тех же данных.

**Блокер**: TA-Lib не собирается на сервере (нужна C-библиотека). План: `apt install libta-lib-dev` (или docker freqtrade) → `freqtrade download-data` → `freqtrade backtesting --strategy T2Momentum`.

## 4. Hummingbot — подготовка для MM — 🟡 ПЛАН (запуск после накопления ws-данных)

**Почему**: Hummingbot — лучший open-source MM-фреймворк (готовые PMM-стратегии, inventory-контроль). Наш MM-сигнал (AUC 0.95) можно интегрировать как фильтр.

**План** (когда ws-данных ≥ 2-4 недели):
1. Установка: `pip install hummingbot` (или docker) на сервере;
2. Стратегия: PureMarketMaking с нашим OBI-сигналом как фильтром (вход в квоту только при подтверждённом направлении);
3. Paper-режим на testnet (binance testnet) — сравнение с нашей самописной MM-логикой;
4. Если Hummingbot-версия лучше — перейти на неё (поддержка сообщества, 50+ бирж).
