### Назначение

**Название:** Unused Resource Reclaimer (УРР)

**Описание:** Утилита для удаления ненужных ресурсов из системы Octopus. Она выполняет следующие задачи:
- Ищет и удаляет старые файлы bak, процессы, сервисы, пустые директории и старые образы Docker.
- Не касается системных журналов, проектных файлов, SSH ключей или любых других безопасных путей.

### 3 bounded улучшения без деструктивных действий

1. **Бounded by health:** Устройство проверяет только здоровые ресурсы.
2. **Бounded by API:** Проверки выполняются через сторонний скрипт `code/run.py`, который обрабатывает ошибки и отклоняет ненужные действия.
3. **Бounded by memory:** Используется ограниченная память для выполнения проверок, чтобы избежать перегрузки системы.
