# Zero-cost методы заработка и риск-лестница (вектор САМООБЕСПЕЧЕНИЕ)

Дата: 2026-07-09. Источник-директива: `~/agents/45_octopus_self_sufficiency_vector.md`.

## Принцип
«От сбора бесплатных сатоши с кранов до торговли на биржах» — но **поэтапно и безопасно**:
сначала всё бесплатное и симуляционное, реальные средства — только за consent gate.

## L0 — Zero-cost, можно развивать сейчас (без реальных денег)
| Вид | Что делать автоматически | Что нужно, чтобы стало ready |
|---|---|---|
| Faucets (сатоши) | Парсинг списка кранов, таймеры, ротация; клейм только в публичный адрес | Публичный адрес кошелька + решение captcha (человек/captcha-сервис) |
| Learn-and-earn | Мониторинг курсов бирж с наградами | Аккаунт + KYC (человек) |
| Airdrops / ретродропы | Eligibility-сканер, напоминания, трекинг | Кошелёк + критерии eligibility |
| Free-tier перепродажа | Оркестрация free-tier вычислений/хранилища | **Проверка ToS провайдера** (может быть запрещено) |
| Контент / данные / SEO | Генерация и публикация ассетов, монетизация | Канал распределения (человек) |
| Баунти за данные/разметку | Матчинг задач, авто-выполнение простых | Аккаунты на платформах |

> Все L0-методы, требующие приватных ключей, используют только публичные адреса.
> Приватные ключи/seed-фразы никогда не запрашиваются и не логируются.

## L1 — Paper-trading (симуляция на реальных ценах)
- Реализовано: `code/run.py` — SMA crossover на BTC/USD, best-effort цены (CoinGecko/Bitstamp/blockchain.info),
  offline-safe. Реальные ордера не отправляются (`real_orders_sent = 0`).
- Цель: набрать историю (`MIN_HISTORY=3`), валидировать стратегию, затем расширять (RSI, mean-reversion, мультит_PAIR).

## L2 — Real funds, строго за consent gate
Условия (все обязательны, отдельной командой человека):
1. `config/consent.json`: `real_funds_unlocked=true`, `exchange_trading_allowed=true`.
2. `max_loss_usd > 0` (стоп-лимит потерь).
3. `approved_exchanges` — явный список.
4. Paper-first: стратегия должна показать устойчивость на L1.
5. Ключи только read+trade (без вывода средств), хранятся вне репозитория, не логируются.

## L3 — Продвинутая real trading (арбитраж, маркет-мейкинг, мульти-биржа)
Только после устойчивой L2 и отдельной команды. Высокий риск → bounded, с мониторингом и kill-switch.

## Чего делать НЕЛЬЗЯ (согласовано с правилами проекта)
- Реальные деньги/биржи/ключи без явной команды человека (`09_free_servers_only.txt`, `33`, `34`).
- Платные облака/ноды без отдельной команды (`08`, `09`, `23`).
- Unsupervised autoloops с реальными средствами (`13_no_unsupervised_autoloops.txt`).
- Раскрытие секретов/токенов в логах/Telegram (`34`, `32_telegram_drift_guard.md`).
