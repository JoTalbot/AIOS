### 1. Контекст

**Назначение:**
Система **swarm-load-forecaster** предназначена для прогнозирования нагрузки на сеть Octopus. Она собирает реальные метрики системы (CPU, память, диск и сетевое соединение), хранит историю времени рядов, вычисляет средние значения по течению времени, определяет тренды (рост/падение/стойкость) и прогнозирует 1/2/4 часа вперёд с помощью линейной регрессии. Она также генерирует уведомления при нарушении заданных порогов.

### 2. Улучшения

- **Улучшение производительности:** Снижение количества вызовов к серверу для обработки данных.
- **Улучшение безопасности:** Изменение кода с использованием более безопасных методов и функций, таких как замена `eval` на `exec`.
- **Улучшение отзывчивости:** Увеличение скорости выполнения команды при вызове через systemd timer.
