# DCA Telegram-уведомления — настроены

**Скрипт:** `scripts/dca_telegram_report.py` (читает credentials systemd: telegram_token, telegram_owner_chat_id)
**Таймер:** `aios-dca-report.timer` — каждый понедельник 18:00 UTC, полный отчёт (позиции, покупки)
**Тест:** отправлено успешно (sent: True), владелец получил отчёт.

Формат отчёта: вложено, стоимость, PnL $ и %, комиссии, число позиций, последний депозит,
последние покупки (в еженедельном режиме), напоминание о ребалансе.
