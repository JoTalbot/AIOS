# Управление Google и Instagram через диалог в Telegram

Бот AIOS (`run_telegram_bot.py`) управляет **Google** и **Instagram** обычным
«человеческим» текстом (и даже голосом) в чате — без команд и API.

## Как это работает
1. Вы пишете боту фразу («проверь мою почту») или отправляете голосовое.
2. Бот распознаёт намерение и запускает хелпер `run_account_control.py`
   (под `xvfb-run` для браузерных операций).
3. Хелпер работает через **Chrome Twin** (ваш профиль Chrome: Google
   `jo.talbot@gmail.com`, Instagram `@jo.talbot`), почта — через **IMAP/SMTP**.
4. Бот отвечает текстом и/или присылает **скриншоты и файлы**.

## Google
| Фраза | Действие |
|---|---|
| «проверь мою почту» / «сколько непрочитанных» | список писем |
| «найди письмо от github» | поиск по почте |
| «прочитай письмо 2» | полный текст письма (по номеру из списка) |
| «ответь на письмо 1: привет, спасибо» | ответ на письмо (с подтверждением) |
| «кто я в гугле» | какой аккаунт залогинен |
| «события на сегодня» / «план на неделю» | события + скрин календаря |
| «добавь событие Встреча завтра в 14:00» | создание события (LLM разбирает) |
| «файлы на диске» | список файлов Диска |
| «скачай файл <имя/id>» | **файл прямо в чат** |
| «создай документ, тема …, текст: …» | создание Google-документа |
| «отправь письмо …» | письмо с подтверждением |
| «покажи календарь/диск/почту» | скриншоты |

## Facebook, TikTok, OLX (Chrome Twin)
| Фраза | Действие |
|---|---|
| «покажи фейсбук» / «фб» | профиль: имя, друзья, город, bio + скрин |
| «лента фейсбука» | последние посты ленты |
| «тикток» | профиль: имя, подписчики, подписки, лайки + скрин |
| «олх» / «мои объявления» | OLX: имя, число объявлений, баланс + скрин |
| `/fb` · `/tiktok` · `/olx_account` | команды |

## Instagram
| Фраза | Действие |
|---|---|
| «директ» | список чатов Direct |
| «покажи чат Серега» | последние сообщения чата |
| «напиши в директ Серега: привет» | отправить в существующий чат (с подтверждением) |
| «напиши в директ @user: текст» | новый чат |
| «покажи мой инстаграм» / «сколько подписчиков» | профиль + скрин |
| «мои посты» / «пост /p/CODE/» | посты |
| «лайкни <ссылка>» | лайк (с подтверждением) |
| «подпишись на @…» / «отпишись от @…» | подписка/отписка |
| «скрин моего инстаграма» | фото профиля |

> **Сторис**: Instagram web не поддерживает создание сторис из браузера —
> только из мобильного приложения.

## Голосовое управление 🎙
Отправьте боту **голосовое сообщение** — бот распознает речь (Gemini API)
и выполнит команду: «проверь почту», «покажи инсту», «отправь письмо …».
Проверено: «Проверь мою почту.» → выполняется.

## Дайджесты и уведомления (автоматически)
- **Утренний дайджест** (`run_digest.py`): почта + события дня + Instagram —
  каждый день в **05:00 UTC (08:00 Киев)** через `aios-digest.timer`.
- **Алерты на важные письма** (`run_mail_alerts.py`): каждые 15 минут
  проверяет IMAP на письма с ключевыми словами (срочно, важно, invoice,
  security, github и т.п., настраивается `MAIL_ALERT_KEYWORDS` в `.env`),
  шлёт уведомление; повторы исключены state-файлом.
- Вручную: команда **«дайджест»** или `/digest` в чате.

## Безопасность
- Опасные действия (отправка письма/ответа, создание события, лайк,
  подписка, сообщение в Direct) — **только после «да»**.
- Фото/файлы из чата сохраняются локально.
- Браузерные операции — под X-дисплеем (headless блокируется).
