1. **Ввод текста**: Пользователь вводит детализированную информацию о продукте.
2. **Суммаризация引擎**: Использует сложные методы лингвистической обработки для извлечения важных элементов.
3. **Генерация вывода**: Возвращает краткое описание вводного текста, выделяя ключевые моменты с дополнительным контекстом.
