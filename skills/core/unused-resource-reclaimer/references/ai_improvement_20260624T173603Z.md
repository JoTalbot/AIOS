### Назначение

**Ключевое назначение:** Улучшение навыка "unused-resource-reclaimer" для автоматического удаления ненужных ресурсов с минимальными рисками и краткими действиями.

### 3 bounded улучшения без деструктивных действий

1. **Бounded by Health Check:**
   - Проверка состояния системы перед выполнением сканирования.
   - Если система не здорова, сканирование отменяется и сообщение о проблемах выдается.

2. **Бounded by API Limits:**
   - Установка ограничений на количество проверок в день для устойчивости к нагрузке.
   - При достижении лимита повторная проверка будет запланирована через определенное время.

3. **Бounded by Time of Day:**
   - Снижение частоты выполнения сканирования по ночам, чтобы избежать нежелательных воздействий на работу системы.
   - Зависит от текущего времени суток и установленного интервала.
