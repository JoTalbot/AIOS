# AIOS: сценарии приложений Android

Обновление добавляет безопасные сценарии для реального телефона, подключённого через WireGuard и AIOS Companion.

## Приложения

| Приложение | Пакет | Режим |
|---|---|---|
| WhatsApp | `com.whatsapp` | Поиск чата, черновик, отдельное подтверждение отправки |
| iMe Messenger | `com.iMe.android` | Черновик в вручную открытом чате, отдельное подтверждение отправки |
| Uklon Passenger | `ua.com.uklontaxi` | Статус, уведомления, черновик маршрута; без заказа поездки |
| Uklon Driver | `ua.com.uklon.uklondriver` | Статус и подтверждаемое открытие |
| EasyWay | `com.eway` | Статус, уведомления, черновик маршрута; без фоновой геолокации |
| A-Bank | `ua.com.abank` | Только уведомления, статус и подтверждаемое открытие |
| Privat24 | `ua.privatbank.ap24` | Только уведомления, статус и подтверждаемое открытие |

## Telegram-команды

### WhatsApp на телефоне

- `WhatsApp статус`
- `открой чат WhatsApp: Имя`
- `WhatsApp черновик: текст ответа`
- `прочитай WhatsApp` — читает только видимую часть уже открытого чата по явной команде.

Процесс отправки всегда состоит из двух шагов:

1. Подтвердить вставку черновика в текущий чат.
2. После проверки текста на экране отдельно подтвердить нажатие **«Отправить»**.

Перед нажатием «Отправить» AIOS ещё раз сверяет текст в поле ввода с подтверждённым черновиком. Если пользователь сменил чат или текст, отправка блокируется.

### iMe

1. Открыть нужный чат вручную на телефоне.
2. Написать: `iMe черновик: текст`.
3. Подтвердить вставку и отдельно — отправку.

### Uklon

- `Uklon статус`
- `открой Uklon`
- `открой Uklon Driver`
- `маршрут Uklon: откуда -> куда`

Последняя команда открывает Passenger и сохраняет короткоживущий приватный черновик маршрута. Она **не** создаёт заказ, не принимает поездку и не инициирует списание денег.

### EasyWay

- `EasyWay статус`
- `открой EasyWay`
- `маршрут EasyWay: остановка или адрес`

EasyWay зарегистрирован как `com.eway`. Маршрут хранится только в краткоживущем файле с правами `0600`; GPS не включается и не читается в фоне.

### Банки

- `A-Bank статус`, `открой A-Bank`
- `Privat24 статус`, `открой Privat24`

Нет сценариев для балансов, карт, OTP/PIN, биометрии, переводов, платежей или подтверждений банковских операций.

## Защита данных

- Companion по умолчанию возвращает **обезличенную** структуру UI: координаты, роли и package активного окна, без текста экрана.
- Полный текст UI запрашивается только внутри подтверждённого сценария и не записывается в логи.
- Для активного действия AIOS проверяет package активного приложения. Если Companion не может подтвердить foreground package, вставка и нажатия блокируются.
- Тексты черновиков и маршрутов имеют короткий TTL и сохраняются с правами `0600`.
- OTP/PIN-подобные последовательности, номера карт и телефоны маскируются в выдаче сообщений и уведомлений.
- HTTP gateway Companion привязывается только к адресу WireGuard `10.203.x.x`, а не к Wi‑Fi/мобильной сети.

## Ограничения

- Сообщения не отправляются автоматически.
- Открытие WhatsApp-чата может пометить его как прочитанный — перед этим показывается предупреждение.
- Доставка сообщения не заявляется как факт: после подтверждения AIOS сообщает только о нажатии кнопки отправки.
- Если пользователь вручную меняет активное приложение или текст на телефоне, сценарий останавливается безопасно.
