**Auto-Document Summarizer Skill**

### Описание

Этот сkill автоматизирует суммирование описаний продуктов, предоставляя краткие обзоры, которые выделяют ключевые характеристики и преимущества.

### Как работает

1. **Ввод текста**: Пользователь вводит детализированные данные о продукте.
2. **Суммаризация引擎**: Использует передовые методы натурализованного языка для извлечения важных деталей.
3. **Генерация вывода**: Возвращает краткое обновление исходного текста, выделяя ключевые моменты с дополнительным контекстом, если необходимо.
