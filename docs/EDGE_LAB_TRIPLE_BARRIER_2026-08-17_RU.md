# Edge Lab: triple-barrier метки для ML Directional v2 — ОТКЛОНЕНО

**Дата:** 2026-08-17 | **Статус:** REJECTED (гипотеза закрыта данными)
**Гипотеза:** AUC 0.533 развёрнутой модели — артефакт шумной метки «следующий бар
вверх/вниз»; барьерные метки (TP+2%/SL−1%/таймаут 24ч, первый тач по intrabar
high/low, при таймауте — знак close) дадут более обучаемый сигнал.

## Методика

- Те же 13 scale-free фич и гиперпараметры CatBoost v2, что в проде.
- Purge-сплит 70/30: train-бары обязаны ЗАКРЫТЬ метку до начала теста
  (методология purge из long-horizon чекера — без утечки).
- Метрики: AUC, hit@0.65, coverage, engine-симуляция (long при prob≥q90(train),
  барьерные выходы, издержки 0.5%/round-trip).
- 35 символов, binance 1h.

## Результат

| Метка | Средний AUC | Медиана AUC |
|---|---:|---:|
| triple-barrier | **0.502** | 0.504 |
| next-bar (текущая) | **0.524** | 0.520 |

Triple-barrier не лучше next-bar ни в среднем, ни на большинстве символов;
hit@0.65 нестабилен (None/выбросы на обеих метках); симуляции отрицательны
у обеих (−0.3…−0.8% за сделку — издержки 0.5% съедают барьерный спред).

## Вывод

1. **Метки не были узким местом.** Шум метки объяснял лишь малую часть слабости
   модели; на данных фичах (технические, scale-free) направленного сигнала
   для 1h-горизонта нет в принципе.
2. Направление «улучшить метки» закрыто. Оставшиеся непроверенные гипотезы
   для Directional-сигнала: внешние данные (funding/OI-кросс-секция,
   on-chain), но исторические эксперименты (funding, ML-CS, MTF, news) уже
   отрицательны — вероятность успеха низкая.
3. Практический вывод для системы: Directional v2 остаётся консервативным
   paper-контуром; экономическая ценность контура — сохранение капитала
   (подтверждено scoreboard: −0.38% при рынке −7.35%), а не заработок.
   Заработок в текущем дизайне дают пассивные корзины (DCA/бенчмарк-топ-10).
