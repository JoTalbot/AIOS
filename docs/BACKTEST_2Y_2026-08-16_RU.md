# Бэктест: «если бы торговля началась 2 года назад»

**Дата:** 2026-08-16 | Скрипт: `scripts/backtest_2y.py` (+`tests/test_backtest_2y.py`, 17 тестов)

## Методика
- Данные: Binance Futures 1h klines, 8 активов (BTC ETH SOL XRP BNB DOGE ADA LINK),
  2 года (2024-08-15..2026-08-15), 17 520 баров/актив (пагинация 1500);
- Модель: CatBoost обучен на первых 70% каждого символа (честный OOS);
  **OOS-окно = последние ~30% (≈7 месяцев, бар 12264..17520)**;
- Движок: текущая live-конфигурация (BUY_LONG + ML≥0.65 + conf≥0.88, TP 2%/SL 1%/
  trail 1.0, 1 позиция, kill-свитчи 0.25%, издержки ~0.5% на круг, $200/сделку, $10k);

## Результаты
| Период | Сделок | WR | PF | PnL | Комментарий |
|---|---:|---:|---:|---:|---|
| **OOS (честный)** | 23 | 35% | 0.41 | **−26.45$** | медвежье окно |
| Весь 2-летний (справочно, prob. на train) | 144 | 58% | 1.15 | +27.53$ | НЕ честно (подгонка) |
| BTC buy&hold 2 года | | | | **+9.8%** | |
| BTC buy&hold OOS-окно | | | | **−30.9%** | |

## Выводы
1. **Честный OOS убыточен** (−26.45$, PF 0.41): 15 стопов / 4 trailing / 4 TP.
2. **Но стратегия обгоняет buy&hold в медвежьем окне** (−0.26% vs −30.9%): защита
   капитала работает (kill-свитчи + стопы), просто не зарабатывает.
3. «Прибыль» +27$ за 2 года — артефакт: появляется только при сигналах на train-части.
4. ML-гейт режет активность: 23 сделки за 7 месяцев OOS.
5. **Итог: на 2-летнем горизонте текущая стратегия убыточна, но это «страховка»,
   а не доходность** — согласуется со всеми 10 экспериментами (направленного edge нет).

## Сравнение (полная картина за сессию)
- 1-летний OOS (ранее): −13.7$ / PF 0.64 / 23 сделки;
- 2-летний OOS (теперь): −26.45$ / PF 0.41 / 23 сделки;
- Вывод: масштаб убытка растёт с горизонтом (больше стопов), edge не появляется.
