# python_to_systemd_packaging

Цена: $30
Максимальное время выполнения: 1200 секунд
Лимит CPU: 100%
Лимит памяти: 512 МБ
Результат: service+timer+runbook

## Входные данные

- описание задачи;
- целевая система или репозиторий;
- критерии приёмки;
- idempotency key;
- подтверждение оплаты или бюджета.

## Безопасность

Внешние изменения выполняются только через глобальный lock. Автоматическое принятие заказов отключено.
