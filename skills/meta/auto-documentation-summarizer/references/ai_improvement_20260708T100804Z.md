### Назначение

**Auto-Document Summarizer Skill**: Этот инструмент автоматизирует сжатие описаний продуктов, предоставляя краткие и содержательные версии, которые выделяют ключевые характеристики и преимущества.

### Как работает

1. **Ввод текста**: Пользователь вводит детализированные данные об продукте.
2. **Суммаризация引擎**: Использует сложные методы натурализованного языка для извлечения важных данных.
3. **Генерация вывода**: Возвращает сжатую версию вводимого текста, выделяя ключевые моменты с дополнительным контекстом.

### Интеграция

- **Синтез продукта и описания**: Этот инструмент integrates seamlessly в различные приложения для онлайн-э-commerce, автоматизируя описание продуктов.
  
- **Пользовательский интерфейс**: Предоставляет простой интерфейс для непосредственного взаимодействия с процессом сжатия.
