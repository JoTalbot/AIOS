### Назначение

**Node Health Orchestrator (NHO)** — это инструмент для автоматической проверки состояния всех виртуальных машин (VMs) на основе файлов `health.json`. Он обеспечивает следующие функции:

1. **Объединение данных о состоянии всех нод**: Недавние отчеты и текущее состояние каждого узла.
2. **Активация автономных операций**: Автоматическое восстановление после сбоев или катастрофических ситуаций.
3. **Обновление рейтинга**: Обновление оценки состояния нод в зависимости от их текущего состояния.
4. **Уведомления об устойчивых проблемах**: Уведомления оpersistent failures.
5. **Интеграция с free-tier-orchestrator**: Синхронизация данных с другими инструментами Octopus.

### Бounded улучшения

1. **Бесконтрольный автостарт** — запуск без согласования
2. **Безопасное обновление системы** — только через `code/run.py` и `generic_skill
