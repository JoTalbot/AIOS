# skill-usage-audit

## Описание

Этот скил отслеживает, какие скилы используются, и создает отчеты об их активности.

## Алгоритм

1. Сканирует логи на предмет запусков скилов
2. Подсчитывает частоту использования каждого скила
3. Создает отчет в формате JSON и Markdown
